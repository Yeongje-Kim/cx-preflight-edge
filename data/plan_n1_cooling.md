# 통합시운전 시험절차서 IST-COOL-N1-01
## 냉동기 N+1 자동 전환 시험 (냉수 계통)

> 본 문서는 Cx-Preflight Edge 기능검증용 예시 절차서다. 모든 수치(허용시간, 온도 범위, 부하)는
> 임의 설정값이며, 실제 적용 시에는 프로젝트별 승인 시험계획서의 기준을 사용한다.

## 1. 시험 개요
- 목적: 주 냉동기 CH-1 트립 시 대기 냉동기 CH-2와 냉수펌프 CHWP-2가 자동 기동하고, 냉수 공급온도가 허용 범위로 회복됨을 확인한다.
- 대상 설비: 냉동기 CH-1(주), 냉동기 CH-2(대기), 냉수펌프 CHWP-2, 냉수 공급온도 센서 TT-CHWS-01, 부하기 LB-01
- 관련 시퀀스: SOO-COOL-01 §3.2 대기기 자동 전환
- 시험 등급: Level 4 통합시스템시험(IST), 부하기 200 kW 인가 상태

## 2. 공통 사전조건
- BMS 트렌드 기록 1초 주기 활성
- 부하기 LB-01 200 kW 이상 인가, 30초 이상 안정
- 냉수 공급온도 6~8 °C

## 3. 공통 중단 조건
- 냉수 공급온도(CHWS_T_SUP)가 14 °C를 초과하면 시험을 중단하고 CH-1을 수동 복구한다.

## 4. 시험 단계

### S1 초기 상태 확인
- 조치: 시험 시작 전 설비 상태를 BMS 화면에서 확인한다.
- 사전조건: CH-1 운전 중(CH1_STATUS = 1), CH-2 정지(CH2_STATUS = 0)
- 기대 결과: 냉수 공급온도(CHWS_T_SUP) 6~8 °C를 10초 이상 유지. 허용시간 20초.
- 복구: 해당 없음(상태 변경 없음)

### S2 부하 안정 확인
- 조치: 부하기 LB-01 출력을 200 kW로 유지한다.
- 사전조건: 부하기 운전 중(LOAD_KW > 0)
- 기대 결과: LOAD_KW 200 kW 이상을 10초 이상 유지. 허용시간 30초.
- 복구: 부하기 출력을 0 kW로 하강한다.
- 상태 변경: 있음

### S3 CH-1 모의 트립
- 조치: CH-1 트립 접점을 모의 입력한다.
- 사전조건: CH1_STATUS = 1, CH2_STATUS = 0
- 트리거: CH1_TRIP = 1 (접점 입력 시각을 단계 시작으로 본다)
- 기대 결과: CH-1 정지(CH1_STATUS = 0) 5초 이내
- 중단 조건: CHWS_T_SUP > 14 °C
- 복구: 트립 접점을 복구하고 CH-1을 재기동한다.
- 상태 변경: 있음

### S4 대기기 기동 지령 확인
- 조치: BMS 자동 전환 로직의 기동 지령 출력을 확인한다.
- 사전조건: CH1_TRIP = 1
- 기대 결과: CH2_CMD = 1 이 10초 이내 출력
- 중단 조건: CHWS_T_SUP > 14 °C
- 복구: 자동 전환 로직을 비활성하고 수동 운전으로 전환한다.

### S5 CH-2 운전 확인
- 조치: CH-2 기동 및 운전 상태를 확인한다.
- 사전조건: CH2_CMD = 1
- 기대 결과: CH2_STATUS = 1 이 30초 이내 성립
- 중단 조건: CHWS_T_SUP > 14 °C
- 복구: CH-2를 수동 정지한다.
- 상태 변경: 있음

### S6 냉수펌프 CHWP-2 연동 기동
- 조치: CH-2 운전에 연동한 냉수펌프 기동을 확인한다.
- 사전조건: CH2_STATUS = 1
- 기대 결과: CHWP2_STATUS = 1 이 20초 이내 성립
- 중단 조건: CHWS_T_SUP > 14 °C
- 복구: CHWP-2를 수동 정지한다.
- 상태 변경: 있음

### S7 냉수 공급온도 회복
- 조치: 공급온도 트렌드를 관찰한다.
- 사전조건: CHWP2_STATUS = 1
- 기대 결과: CHWS_T_SUP 6~8 °C로 60초 이내 회복하고 10초 이상 유지
- 중단 조건: CHWS_T_SUP > 14 °C
- 복구: CH-1을 수동 재기동한다.

### S8 정상 상태 복구
- 조치: 트립 접점을 복구하고 CH-1을 재기동한 뒤 CH-2를 대기로 복귀시킨다.
- 사전조건: CH2_STATUS = 1
- 트리거: CH1_TRIP = 0 (접점 복구 확인 시각을 단계 시작으로 본다)
- 기대 결과: CH1_STATUS = 1 이 60초 이내, CH2_STATUS = 0 이 90초 이내
- 복구: 수동 운전으로 전환한다.
- 상태 변경: 있음

## 5. 기록
각 단계의 시작·종료 시각, 판정(PASS/FAIL/ABORT), 판정 근거가 된 태그 값과 시각을 기록한다.
