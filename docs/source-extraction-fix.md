# AI 추출 원문 대조 보완

2026-09-07. UI 검증 중 발견한 S2 허용시간·유지시간 뒤바뀜 후속 수정.

## 바뀐 동작

1. 추출 프롬프트에서 `이상`과 `초과`, `허용시간`과 `유지시간`을 명시적으로 구분한다.
2. JSON 스키마 통과 후 원문에서 명시된 태그·연산자·임계값·허용시간·유지시간·상태변경 여부를 별도 코드로 대조한다. 기대조건뿐 아니라 사전·트리거·중단 조건도 대조한다.
3. 불일치한 필드와 원문 값을 모델에 전달해 재추출한다. 계속 실패하면 해당 원문 대조를 통과한 기준 단계만 대체하며, 대체 단계 목록을 기록한다. 검증되지 않은 값을 조용히 고치는 방식은 사용하지 않는다.
4. AI 모드 승인 API는 저장된 원문과 규칙을 다시 대조한다. 불일치는 강제 승인으로 우회할 수 없다. 이전에 승인된 잘못된 규칙도 재생 전에 다시 검사한다.
5. UI에 AI 원문 수치 대조 통과 단계 수와 기준본 대체 단계 수를 표시한다. 원문 대조는 AI 정확도 평가 전체를 대신하지 않는다.

## 추가로 수정한 재현 오류

- JSON 역방향 스캔이 이스케이프 문자를 포함한 출력에서 바깥 객체를 놓치는 문제: 표준 JSON 디코더로 객체 경계를 찾도록 수정.
- 보드 회귀에서 세션 메타 JSON을 쓰는 순간 조회하면 빈 파일을 읽는 문제: 같은 프로세스의 읽기·쓰기 잠금, 갱신 잠금, 원자적 JSON 파일 교체 적용. 여러 프로세스 간 메타 병합 잠금은 제공하지 않으며 현재 단일 서버 프로세스 범위다.

## 검증

- 로컬·보드 pytest 78개 통과(기존 58개 + 신규 20개).
- 시간 뒤바뀜, `>=`→`>`, 임계값·태그 변경, 원문 시간 누락, 단계 누락, 잘못된 기준본 폴백 차단, 명시값이 바뀐 원문, JSON 이스케이프, 동시 저장·조회 회귀 포함.
- 과거 실패 세션 `cx-20260906-225547-b973`에 대한 실제 보드 강제 승인 및 재생 요청 모두 HTTP 409. 증거: `screens/source-fix/old-session-blocked.json`.

## 적용 범위

현재 태그가 명시된 `- 기대 결과:` 등의 단일 행과 숫자·초 단위·`~` 범위·비교 연산자 형식에 대한 보수적인 대조다. 임의의 한국어 절차서, 분 단위, 복잡한 대안 조건, 이미지·표 등까지 의미를 보장하는 범용 파서는 아니다. 지원하지 않거나 모호한 표현은 추출 성공으로 처리하지 않는다. 자연어 조치·복구 문장의 의미 전체와 공통 절차의 모든 요건을 검증하는 기능은 아니다. 엔지니어 원문 검토가 계속 필요하다.

기준본은 AI 출력을 평가하는 유일한 진실로 사용하지 않는다. 원문에서 읽은 값을 비교하며 기준본 대체 시에도 원문 대조를 수행한다. `preflight_warn`은 명시적인 결함 주입 시연이므로 기존 오류 승인 게이트와 분리해 유지한다.
