# 입력 검증과 AI 활용 범위

출품작: **온디바이스 AI 기반 데이터센터 시운전 검증·기록 시스템**

2026-09-08 기준. 이 문서는 현재 동작과 지원 범위를 설명한다. 실험 결과는 [NPU 격리 검증](board/hardening-2026-09-08/README.md)에 별도로 기록한다.

## 절차 구조화

- 입력은 `### S1 단계명`과 `- 사전조건:`, `- 트리거:`, `- 조치:`, `- 기대 결과:`, `- 중단 조건:`, `- 복구:`, `- 상태 변경:`을 사용하는 Markdown이다. 별표 글머리표와 들여쓴 이어쓰기 행도 읽는다.
- 제목·조치·복구 문장은 원문에서 그대로 보존한다. 줄바꿈은 공백으로 연결한다. 이 문구를 AI가 자유롭게 다시 쓰게 하지 않는다. 추출 통계의 `narrative_source`와 `narrative_restored_fields`에 처리 내역을 남긴다.
- AI가 구조화한 사전·트리거·기대·중단 조건의 태그, 비교 연산자, 수치, 기대조건의 허용시간·유지시간, 상태 변경 여부를 원문과 대조한다. 불일치하면 최대 두 번 재시도한다. 기준본 대체가 필요한 경우 그 단계 역시 원문 대조를 통과해야 한다.
- `==`, `!=`, `<`, `<=`, `>`, `>=`, `~` 범위와 지원하는 한국어 비교 표현, 초 단위 시간을 사용한다. 모호한 대안·부정 표현, 쉼표 숫자, 해석되지 않은 추가 수치·연산자, 분 단위 유지시간 등은 자동 승인용 규칙으로 받지 않는다.
- `precond_wait_sec`와 `trigger_wait_sec`는 문서에서 추출하는 기대조건 시간이 아니다. AI 출력으로 바꾸지 않고 각각 10초와 120초의 앱 기본값을 사용한다. 제공된 기준본의 S8 트리거 대기시간은 180초이다. 엔지니어는 승인 화면에서 프로젝트에 맞는 대기시간을 별도로 검토해야 한다. 추출 결과 비교에서는 이 두 실행 설정을 제외하고 기본값 적용을 따로 검사한다.

지원 형식에 대한 원문 대조이며, 모든 한국어 문장의 의미를 이해하거나 공통 주의사항까지 실행 규칙으로 변환하는 범용 문서 해석기는 아니다. 실제 승인 기준과 태그 단위의 일치 여부는 엔지니어가 검토한다.

## 시험 기록의 AI 역할

판정 요약·상태·시간·측정 근거는 규칙 엔진의 결과로 작성한다. AI는 실제 실패·중단·보류 사유에 맞춰 제시된 점검 항목의 ID를 선택하고, 앱이 해당 항목의 고정 문안을 표시한다. 각 항목에는 단계와 사유 코드가 연결된다.

따라서 AI 자유 문장에 포함된 새 기준값, 근거 없는 고장 원인, 임의 설비 교체 지시, 깨진 문자를 보고서에 싣지 않는다. 잘못된 ID는 항목별로 제외해 올바른 선택까지 버리지 않는다. 유효한 선택이 없으면 한 번 재시도하고, 계속 실패하거나 모델을 사용할 수 없으면 근거별 기본 항목을 사용한다. 선택 출처와 재시도·제외·오류 통계를 보관한다.

이 방식은 **자유 문장 생성 품질을 높인 결과가 아니라 AI의 역할을 근거별 항목 선택으로 제한한 설계 변경**이다. 고정 문안은 점검 제안이며 설비 고장 원인의 확정이나 직접 제어가 아니다.

## 오류와 예외 처리

| 입력 또는 상황 | 처리 |
|---|---|
| 잘못된 모드·시연 종류·속도·난수 시드·강제승인 값 | HTTP 400으로 거절하며 잘못된 실행 요청으로 세션을 소모하지 않음 |
| 승인 시 명시적으로 전달한 빈 규칙 또는 잘못된 규칙 | 저장 규칙으로 조용히 대체하지 않고 거절 |
| 원문과 다른 제목·조치·복구 또는 판정 조건 | AI 모드 승인·실행 차단, 강제승인으로 우회 불가 |
| 구조화·실행·보고서 생성 중 삭제 | HTTP 409로 거절 |
| 모델의 잘못된 태그 매핑·모순 후보 구조 | 경고 또는 해당 항목 제외, 부가 기능 오류로 전체 추출 중단 방지 |
| CSV의 중복 헤더·누락된 시간·추가 열·비수치 입력 | 행·열 정보가 있는 오류 반환 |
| NaN·무한대 센서 측정값 | 결측으로 취급, 정상값으로 판정하지 않음 |
| NaN·무한대 기준값, 빈 시험 계획 | 규칙 스키마에서 거절 |
| 중복·역행·비유한 시각 | 엔진 상태를 바꾸기 전에 거절 |
| 네트워크 인터페이스 조회 실패 또는 통신 점검 생략 | 미확인으로 남기며 차단 성공으로 계산하지 않음 |

## 검증 자료와 남는 범위

`data/evaluation/procedures.json`은 냉동기·펌프·공조기·밸브·압력·경계조건으로 구성한 합성 절차서 6건 20단계이다. 기대 규칙을 명시해 실제 모델의 구조화 결과와 비교한다. 개발 중 확인한 고정 회귀 자료로서, 독립된 현장 평가 자료나 범용 정확도 추정치는 아니다.

실제 현장 효과를 주장하려면 비식별 현장 절차서·태그 목록·과거 측정값과 엔지니어 정답을 추가해 누락 검출, 오탐, 규칙 수정량, 검토 시간, 보고서 수정량을 평가해야 한다. PDF·이미지 OCR, 실시간 BMS 수집, 다중 사용자 인증·다중 서버 운영은 별도 구현 범위다. 설비를 직접 제어하지 않는다.
